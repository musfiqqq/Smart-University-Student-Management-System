# Smart University Student Management and Result System

PROG 102 (Structured Programming Language Sessional) project, Department of IoT & Robotics Engineering, UFTB.

A menu based C program to add, view, search, update and delete students, enter marks of 5 subjects for 8 semesters, and get grade, SGPA, CGPA, pass/fail, statistics and top student.

Team: Musfiqur Rahman (2501011), Ali Akbar (2501016), Ashraful Islam (2501019), Rakib Hasan Akash (2501024)

## Run
```
gcc main.c -o main
./main
```
